📰 DailyPulse — Real-Time News Website (Very much in beta)
A sleek, responsive news platform built with Next.js and powered by NewsAPI.org. Stay updated with the latest headlines, organized by category, beautifully designed with modern UI components.



🚀 Features
🕒 Real-time News — Powered by NewsAPI.org

📂 Category Filtering — Browse news by topics like tech, business, sports, etc.

🌗 Light/Dark Mode — Seamless theme switch

🖼️ Image Fallbacks — Clean UI even with broken or missing media

⚡ Local Caching — Smart cache to minimize API hits and improve performance

🛠 Tech Stack
Framework: Next.js 15.2.4

UI: Tailwind CSS, shadcn/ui

Language: TypeScript

Library: React 18
